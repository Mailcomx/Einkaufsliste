    Hinweis zur Nutzung & Datenschutz:
    Diese Web-App ist ein rein privates, nicht-kommerzielles Projekt. Alle eingegebenen Einkaufslisten und Favoriten werden ausschließlich lokal im Browser (LocalStorage) des jeweiligen Endgeräts gespeichert und nicht an einen eigenen Server übertragen. Beim Teilen einer Liste werden die Daten kodiert direkt über den generierten Link übermittelt.

    Das Hosting der Seite erfolgt über GitHub Pages (GitHub Inc.). Dabei werden technisch bedingt Verbindungsdaten (wie die IP-Adresse) durch den Hoster verarbeitet. Die Nutzung erfolgt auf eigene Verantwortung; eine Gewähr für die dauerhafte Verfügbarkeit oder gegen Datenverlust im Browser-Speicher wird nicht übernommen.
